# Minimal Intro Runtime

`minimal_intro` is the universal external-cue development player.
`minimal_intro_packed` embeds the exported project and compiles only the
optional runtime systems selected by the generated project manifest.

## Build

```powershell
cmake -S . -B build
cmake --build build --config Release --target minimal_intro
cmake --build build --config Release --target minimal_intro_packed
```

The standard target reads project cues/assets from disk and retains every
supported subsystem. The packed target reads `build/packed_assets.h` and
`build/packed_features.cmake`, normally generated by the editor or `pack_cli`.

When packing manually:

```powershell
.\build\bin\Release\pack_cli.exe <cues.txt> build\packed_assets.h <pack_cache.txt> <workspace-root>
cmake -S . -B build
cmake --build build --config Release --target minimal_intro_packed
```

The configure step after packing is required so CMake dependency selection
matches the generated `HIMYM_USE_*` C++ macros.

Both runtimes preserve explicit Win32/WGL frame flow, exit on ESC or Alt+F4,
and support shader, image, animated-sprite, text, scrolling text, pixel,
particle, music, procedural mesh, and glTF cue paths when enabled.

See `BUILD.md`, `PR/guides/EDITOR_GUIDE.md`, and
`PACKED_RUNTIME_SIZE.md` for the current workflow and measurements.
